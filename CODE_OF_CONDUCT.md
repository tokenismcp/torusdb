# Code of Conduct

We want this project to be a place where people can ask basic questions, disagree about
design and criticise the cryptography without being attacked.

**Expected:** be respectful and specific; assume good faith; critique code and ideas, not
people; credit others' work; say so when you are unsure.

**Not acceptable:** harassment, insults, discrimination, doxxing, personal attacks,
spam, or pressuring someone to disclose a vulnerability publicly or to withdraw one.

**Scope:** issues, discussions, pull requests and any space that represents the project.

**Enforcement:** maintainers may edit or remove comments, lock threads and block accounts.
Report problems privately to jlabsrd@gmail.com (subject `TorusDB conduct`); reports are
handled confidentially.

Adapted in spirit from the Contributor Covenant (https://www.contributor-covenant.org).
