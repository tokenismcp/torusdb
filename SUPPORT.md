# Getting help

| I want to... | Go to |
|---|---|
| Ask how to use TorusDB, share what I built, discuss ideas | [GitHub Discussions](https://github.com/tokenismcp/torusdb/discussions) |
| Report a bug or a documentation problem | [Issues](https://github.com/tokenismcp/torusdb/issues/new/choose) |
| Propose a feature or a dialect change | Issues (feature request); dialect changes start as a spec edit, see [CONTRIBUTING.md](CONTRIBUTING.md) |
| Report a **security vulnerability** | **Privately**, see [SECURITY.md](SECURITY.md). Never in a public issue or discussion |
| Review the cryptography | [`docs/audit-scope.md`](docs/audit-scope.md) is a brief for independent reviewers; findings are welcome |

This is a v0.x experimental project maintained in spare time and not independently audited.
There is no support contract or response-time guarantee; sponsoring the project
does not change that.

Please include your versions (`torusdb-server --version`, `torussql --version`), the
exact commands you ran and the error text. Never post keys, vault files, tokens or real data.
